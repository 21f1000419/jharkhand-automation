Kindly complete the following steps to pay Stamp duty/eCourt Fees/e Registration Fees online

  • Create User ID using ' Register Now ' option on this page
  • Activate User Id through eKYC using your Digilocker account

  • Use 'Pay Stamp Duty/eCourt Fee Generation/eRegistration Fee Payment' option after logging in
  • Complete data entry with accurate details
  • On completing Online payment, eStamp/ecourt/eRegistration number is generated

  • After eStamp/receipt generation, Download PCP
  • For any help in PCP download, refer to PCP section at the time of printing
  • Use Print eStamp/ecourt Fee/eRegistration Fee option to print
